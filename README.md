# Прототип SOVE App — рабочая копия

Копия прототипа веб-приложения для правок дизайна и сценариев.

## Запустить у себя

```bash
python3 -m http.server 4403
```

Открыть `http://localhost:4403/phone.html?p=home-feed.html` — экран в рамке
телефона. Любой другой экран: подставить его имя вместо `home-feed.html`.

## Что где

- `*.html` — экраны, имя файла = имя экрана
- `assets/css/` — стили
- `assets/js/` — скрипты
- `assets/img/` — картинки

Правила правок — в `CLAUDE.md`.

## Отдать правки

Отдельная ветка на каждую задачу, затем пул-реквест:

```bash
git switch -c alina/<что-меняли>
git add <файлы>
git commit -m "что изменилось"
git push -u origin alina/<что-меняли>
```

В `main` напрямую не пушим.

## Сторонние компоненты

- three.js r128 — `assets/js/vendor/three.min.js`, лицензия MIT (3D-план в «Планировке»). Своя копия: на сервере демо политика безопасности (CSP) разрешает только скрипты с нашего адреса.
